Skwiggle Backend

Skwiggle Backend is a tiny server that sits behind the Skwiggle drawing game. It is for the owner.

Right now it answers with a simple message that says it is running. It is configured to deploy on Railway and restart if it fails.

This app is checked every morning by Control Troll.

Latest change. Created the backend with a basic running check. Added a Railway config so it can deploy and restart on failure.
